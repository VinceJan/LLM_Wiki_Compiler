## 零、Claude Code CLI 可行性验证结论（2026-04-11）

### 问题
Claude Code CLI 在 Windows 下报错："Claude Code on Windows requires git-bash"
根因：用户 Git 安装在非标准路径 `E:\Develop_tools\Git\`，Claude 自动检测失败。

### 解决方案
设置环境变量：
```
CLAUDE_CODE_GIT_BASH_PATH=E:\Develop_tools\Git\bin\bash.exe
```

### 验证结果
- ✅ 设置环境变量后，`claude --print --permission-mode bypassPermissions` 可以正常调用
- ✅ 成功连接 DashScope 的 `qwen3.6-plus` 模型
- ✅ WSL 方案不可行（claude.exe 本质是 Windows 进程，内部检测不变）
- ✅ **方案 A（Claude Code CLI 子进程调用）确认可行**

### 备选方案
如果环境变量方案出问题，备选：
- 在 WSL Ubuntu 中原生安装 Node.js + `@anthropic-ai/claude-code`（以 Linux 进程运行）

## 二、两种后端方案

### 方案 A：Claude Code CLI 子进程调用

```python
import subprocess
import asyncio

async def ingest_via_claude_code(source_content: str):
    """通过 Claude Code CLI 执行 ingest 操作"""
    
    # 构造 prompt
    prompt = f"""
你是一个 LLM Wiki 编译器。请执行以下操作：

1. 读取以下源内容
2. 提取关键概念和实体
3. 在 wiki/ 下创建/更新对应的概念页面
4. 每个页面使用 [[wikilink]] 语法链接到相关页面
5. 更新 wiki/index.md
6. 在 wiki/log.md 追加操作记录

源内容:
{source_content}
"""
    
    # 启动 Claude Code 子进程
    process = await asyncio.create_subprocess_exec(
        "claude",
        "--print",
        "--permission-mode", "bypassPermissions",
        "--output-format", "stream-json",
        "--include-partial-messages",
        prompt,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE,
        cwd=WIKI_ROOT
    )
    
    # 实时读取输出
    async for line in process.stdout:
        yield parse_stream_json(line)
    
    await process.wait()
```

**优势**：
- Claude Code 内置文件操作、PDF 解析、web 抓取
- Agent 循环自动执行
- 最强泛化能力

**风险**：
- Windows 下 git-bash 依赖问题
- 需要用户有 Claude Code 环境
- `--print` 模式的流式输出格式需验证

    runner = client.beta.messages.tool_runner(

## 三、AGENTS.md Schema 设计

```markdown
# LLM Wiki 编译器

你是一个 LLM Wiki 编译器。你的任务是维护一个结构化的知识库。

## 目录结构
- `raw/` - 原始源文件（不可变，只读）
- `wiki/` - 你生成和维护的互连 Markdown 知识库
- `wiki/index.md` - 内容索引
- `wiki/log.md` - 操作日志

## 页面命名约定
- 概念页: `wiki/concepts/{concept-name}.md`
- 实体页: `wiki/entities/{entity-name}.md`
- 摘要页: `wiki/sources/{source-title}.md`
- 查询页: `wiki/queries/{query-title}.md`

## 页面格式
每个页面必须以 YAML frontmatter 开头：

---
title: 页面标题
created: 2026-04-11
tags: [标签1, 标签2]
source: 原始来源URL或文件
---

正文使用 [[wikilink]] 语法引用其他页面。

## Ingest 流程
当你收到一个 ingest 请求时：

1. 阅读源内容，提取关键信息
2. 识别所有关键概念和实体
3. 对于每个概念/实体：
   a. 检查 wiki/ 下是否已有对应页面
   b. 如果没有，创建新页面
   c. 如果有，更新内容并添加新的关联
4. 创建摘要页 wiki/sources/{title}.md
5. 更新 wiki/index.md，为新页面添加条目
6. 在 wiki/log.md 追加操作记录

## Query 流程
当你收到一个 query 请求时：

1. 先读取 wiki/index.md 了解知识库全貌
2. 搜索相关的 wiki 页面
3. 综合相关信息回答问题
4. 如果有价值，将答案保存为 wiki/queries/{title}.md

## Lint 流程
当你收到一个 lint 请求时：

1. 扫描所有 wiki 页面中的 [[wikilink]]
2. 检查每个链接是否有对应的文件
3. 识别孤立页面（没有被任何其他页面链接）
4. 检查是否有矛盾的陈述
5. 输出检测报告
```

## 四、内容摄入管道

```python
import requests
import fitz  # PyMuPDF for PDF
import docx
import openpyxl

class ContentExtractor:
    """统一的内容提取器"""
    
    @staticmethod
    def from_url(url: str) -> str:
        """URL → Markdown via Jina Reader"""
        resp = requests.get(f"https://r.jina.ai/{url}")
        return resp.text
    
    @staticmethod
    def from_pdf(path: str) -> str:
        """PDF → text"""
        doc = fitz.open(path)
        text = "\n".join(page.get_text() for page in doc)
        return text
    
    @staticmethod
    def from_docx(path: str) -> str:
        """Word → text"""
        doc = docx.Document(path)
        text = "\n".join(p.text for p in doc.paragraphs)
        return text
    
    @staticmethod
    def from_xlsx(path: str) -> str:
        """Excel → text (表格转文本)"""
        wb = openpyxl.load_workbook(path)
        lines = []
        for sheet in wb.sheetnames:
            ws = wb[sheet]
            lines.append(f"## {sheet}")
            for row in ws.iter_rows(values_only=True):
                lines.append("\t".join(str(c) for c in row if c is not None))
        return "\n".join(lines)
    
    @staticmethod
    def extract(file_path: str = None, url: str = None) -> str:
        """统一入口"""
        if url:
            return ContentExtractor.from_url(url)
        ext = file_path.lower().split(".")[-1]
        handlers = {
            "pdf": ContentExtractor.from_pdf,
            "docx": ContentExtractor.from_docx,
            "doc": ContentExtractor.from_docx,
            "xlsx": ContentExtractor.from_xlsx,
            "xls": ContentExtractor.from_xlsx,
            "md": lambda p: open(p).read(),
            "txt": lambda p: open(p).read(),
        }
        return handlers[ext](file_path)
```

## 五、知识图谱数据生成

```python
import re
import os
import json
from pathlib import Path

def build_graph_data(wiki_dir: str) -> dict:
    """从 wiki 目录构建图谱数据"""
    nodes = []
    edges = []
    node_ids = set()
    
    for md_file in Path(wiki_dir).rglob("*.md"):
        rel_path = str(md_file.relative_to(wiki_dir))
        node_id = rel_path.replace("/", "/")
        node_ids.add(node_id)
        
        content = md_file.read_text()
        title = extract_frontmatter_title(content)
        
        # 提取 wikilinks
        wikilinks = re.findall(r'\[\[([^\]]+)\]\]', content)
        
        nodes.append({
            "id": node_id,
            "title": title,
            "links_count": len(wikilinks),
            "type": categorize_page(rel_path)
        })
        
        for link in wikilinks:
            edges.append({"source": node_id, "target": link})
    
    return {"nodes": nodes, "edges": edges}

def extract_frontmatter_title(content: str) -> str:
    """从 YAML frontmatter 提取标题"""
    match = re.search(r'^---\s*\ntitle:\s*(.+?)\s*\n', content, re.MULTILINE)
    return match.group(1) if match else "Untitled"

def categorize_page(path: str) -> str:
    """根据路径分类页面类型"""
    if "concepts/" in path:
        return "concept"
    elif "entities/" in path:
        return "entity"
    elif "sources/" in path:
        return "source"
    elif "queries/" in path:
        return "query"
    return "other"
```
